## Описание программы


**Weather Diary** - это GUI-приложение для ведения дневника погоды. Программа позволяет:
- Добавлять записи о погоде с указанием даты, температуры, описания и наличия осадков
- Просматривать все записи в виде таблицы
- Сохранять данные в JSON-файл и загружать их обратно
- Фильтровать записи по дате и температуре


### Возможности:
- ✅ Добавление записи о погоде
- ✅ Просматривание записей в виде таблицы
- ✅ Сохранение данных в JSON-файл
- ✅ Загрузка данных из JSON-файла
- ✅ Фильтровка записей по дате и температуре



## Инструкция по запуску
- python main.py

### Требования:
- Python 3.7 или выше
- Установленная библиотека Tkinter (обычно идёт в комплекте с Python)
- Установленная библиотека json


### Запуск:
1. Откройте терминал или командную строку
2. Перейдите в директорию проекта:
   ```bash
   cd myProject
   ```
3. Запустите приложение:
   ```bash
   python main.py
   ```


## Примеры использования


### Добавление погоды:
1. Заполните все поля формы:
2. Нажмите кнопку **"Добавить запись"**
3. Погода появится в списке внизу окна


### Сохранение и загрузка:
- Нажмите **"Сохранить в файл"** - данные сохранятся в файл `weather_records.json`




## Валидация данных


Приложение проверяет:
- Все поля должны быть заполнены
